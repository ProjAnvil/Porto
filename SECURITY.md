# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately.

- Preferred channel: open a private security advisory in this repository.
- If that is unavailable, contact maintainers directly and avoid public issue disclosure.

Include:

- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Suggested mitigation (if available)

## Disclosure Policy

- We will acknowledge receipt as soon as possible.
- We will investigate and provide a status update.
- We will coordinate a responsible disclosure timeline with reporters.
