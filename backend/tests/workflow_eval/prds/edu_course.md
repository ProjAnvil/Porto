# 在线教育课程平台 PRD

## 背景与目标

为职业教育机构提供课程售卖与学习交付一体化平台：学员购课、上课、作业、考试、发证全流程线上化。

## 核心实体

课程、章节、课时、学员、订单、学习进度、作业提交、考试卷、证书。

## 功能需求

1. 课程管理：机构上架课程（视频/图文/直播），设置章节与课时、价格与优惠。
2. 学习交付：学员按课时学习，系统记录进度，支持断点续学与倍速播放。
3. 作业与考试：每章节可布置作业，课程结束组织在线考试（题库抽题、防切屏）。
4. 发证：考试合格自动生成电子证书，可公开验证。
5. 学习分析：为机构提供完课率、正确率、活跃度看板。

## 非功能需求

- 视频播放 P95 首帧 < 2s，支持万人并发直播。
- 学习进度与成绩数据不可丢失（可恢复）。
