# 智能仓储物流系统 PRD

## 背景与目标

为电商自营仓提供入库、存储、拣选、打包、出库、干线配送的一体化管理，通过条码与库位算法降低人效成本。

## 核心实体

仓库、库区、库位、SKU、库存记录、入库单、出库单、拣选任务、承运商、运单。

## 功能需求

1. 入库：采购到货登记、质检、上架推荐（按周转率推荐库位）。
2. 库存：实时库存与在途库存，支持批次/效期管理，低于安全库存自动补货建议。
3. 拣选打包：波次拣选生成拣选路径，打包称重校验。
4. 出库配送：对接多家承运商比价下单，运单轨迹回传与异常件预警。
5. 盘点：周期性全盘/抽盘，差异生成调整单并审计。

## 非功能需求

- 库存数据强一致，出入库操作幂等。
- 大促期间拣选任务吞吐 10 万单/日，接口 P95 < 500ms。
