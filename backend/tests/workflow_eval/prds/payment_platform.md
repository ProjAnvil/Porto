# 互联网支付交易平台 PRD

## 背景与目标

面向中小商户提供在线支付能力：用户下单后完成支付、退款、结算，并对高风险交易进行风控审核。
系统需要通知商户和用户支付结果，支持订单状态追踪、支付渠道路由和对账报表。

## 核心实体

用户账户、订单、支付流水、风控规则、通知模板。

## 功能需求

1. 支付发起：支持银行卡/余额/第三方渠道，渠道路由按成功率与费率择优。
2. 退款：全额/部分退款，T+1 结算给商户；退款需风控复核。
3. 风控：高额交易前评估欺诈规则并可能拦截，命中规则需人工复核队列。
4. 通知：支付/退款结果通过站内信与 webhook 通知商户。
5. 对账：每日生成渠道对账单，差异流水生成人工处理工单。

## 非功能需求

- 支付核心链路可用性 99.95%，单笔支付端到端 P95 < 3s。
- 所有资金操作可审计、可幂等重试。
